My Checks - Aide utilisateur

Avec l'application Android pobvol My Checks, vous pouvez facilement et rapidement créer des listes de contrôle personnalisées avec des points de contrôle et des questions, et ensuite enregistrer, analyser et exporter les résultats des inspections dans des rapports PDF. Toutes les données sont sauvegardées automatiquement dans des fichiers SQL. Langues prises en charge : allemand, anglais, espagnol et français.

Tableau de bord & Navigation

Le tableau de bord est votre point de départ. Utilisez les cartes pour naviguer vers vos listes et journaux.

Top ↑

Paramètres & Personnalisation

Appuyez sur l'icône d'engrenage (⚙) pour ouvrir les paramètres. La boîte de dialogue "Paramètres généraux" s'ouvre.

Personnalisez l'apparence, la langue et les catégories. Entrez votre nom dans le champ Inspecteur pour qu'il soit inclus dans les rapports.

Appuyez sur le bouton "Personnaliser la mise en page du rapport PDF" pour ouvrir le "Concepteur de rapports PDF".

Top ↑

Mes Listes de Contrôle

Appuyez sur la carte "Mes Listes de Contrôle" sur le tableau de bord.

Ajouter une liste: Créez rapidement de nouvelles listes avec le bouton **`+`**.

Rechercher & Filtrer: Utilisez l'icône de recherche (🔍) ou filtrez par catégorie.

Éditer / Supprimer: Utilisez les icônes d'édition (✏️) ou de suppression (🗑️).

Commencer l'inspection: Appuyez sur une carte de liste pour démarrer une nouvelle inspection.

Voir les journaux: Appuyez sur l'icône de journal (📋) pour afficher les journaux.

Voir les graphiques: Appuyez sur l'icône de graphique (📋) pour afficher les analyses.

Points de contrôle / Questions

Gérez les points de contrôle et questions. Types de réponses pris en charge : Texte, Nombre, Case à cocher, Boîte combinée (Combobox), Sélection multiple (Multiselect), NFC et Code QR.

- Texte: Saisie de texte flexible

- Nombre: Saisie de valeurs numériques avec limites min/max optionnelles.

- Case à cocher: Bascule Oui/Non

- Boîte combinée: Choix unique avec couleurs de fond optionnelles (vert, jaune ou rouge) en utilisant des balises entre crochets (ex. `sans défaut [green]`, `réparation requise [red]`).

- Sélection multiple: Choix multiples avec balises de couleur entre crochets (ex. `Option 1 [green], Option 2 [red]`).

- NFC: Lire des tags NFC physiques

- Code QR: Scanner des codes QR avec la caméra.

Effectuer des Inspections

Répondez aux questions obligatoires, ajoutez des notes et des photos, et scannez des tags NFC ou des codes QR.

Mes Journaux & Export PDF / SQL

Les rapports PDF au format A4 sont automatiquement enregistrés dans Downloads/MyChecks sous le nom Submission_<id>_Report.pdf.

Top ↑

Sécurité des données & Export SQL

Toutes les données sont stockées localement dans SQLite et exportées sous forme de fichiers SQL.TXT dans Downloads/MyChecks.
