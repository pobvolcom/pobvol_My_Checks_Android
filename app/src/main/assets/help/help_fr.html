My Checks - Aide utilisateur

Avec l'application Android pobvol My Checks, vous pouvez facilement et rapidement créer des listes de contrôle personnalisées avec des points de contrôle et des questions, et ensuite enregistrer, analyser et exporter les résultats des inspections dans des rapports PDF. Toutes les données sont sauvegardées automatiquement dans des fichiers SQL. Langues prises en charge : allemand, anglais, espagnol et français.

Tableau de bord & Navigation

Le tableau de bord est votre point de départ. Utilisez les cartes pour accéder à vos listes de contrôle et Journaux et accédent aux paramètres et à l'aide depuis la barre du haut.

Via l'icône du menu en haut à gauche, vous pouvez consulter le contrat de licence, gérer vos propres blocs de texte, sauvegarder la base de données, importer à nouveau des sauvegardes de la base de données et fermer l'application.

Paramètres

Dans le tableau de bord, cliquez sur l'icône d'engrenage (⚙). La boîte de dialogue «Paramètres généraux » s'ouvrira. Personnalisez l'apparence, la langue préférée et les catégories selon vos besoins. Entrez votre nom dans le champ examinateur. Votre nom sera ensuite transféré dans le procès-verbal et sera produit dans le PDF. Si vous voulez, activez Narrateur (TTS). Les messages de l'application vous seront alors lus.

Mes Listes de Contrôle

Cliquez sur la carte « Mes listes de contrôle » dans le tableau de bord et ouvrez le écran correspondant.

Ajouter une liste de contrôle: Vous pouvez créer de nouvelles listes assez rapidement. Cliquez Il suffit de cliquer sur le bouton **'+'** en bas à droite. Le dialogue s'ouvrira « Ajouter une liste de contrôle ». Dans le champ Titre, saisissez un nom pour votre nouvelle liste, Attribuez une catégorie et, si vous le souhaitez, entrez une courte description. Avec Le bouton « Ajouter » enregistrera vos entrées et créera votre nouvelle liste de contrôle et affiché dans la vue d'ensemble.

Trouver des listes de contrôle: Appuyez sur l'icône de recherche (🔍) dans la barre supérieure pour Trouvez des listes de contrôle par titre, description ou catégorie.

Filtrez les listes de contrôle par catégorie: Filtrez la liste en cliquant sur un Catégorie (Santé, UVV, etc.). Cliquer sur Tous supprime à nouveau le filtre.

Modifier une liste de contrôle: Dans une carte de checklist, appuyez sur l'icône Modifier (), ✏️ la fenêtre « Modifier la liste de contrôle » s'ouvre. Ici, vous pouvez sélectionner le titre, le Personnalisez la catégorie et la description.

Copie de la liste de contrôle: Dans une fiche de checklist, appuyez sur l'icône de copie (📄) pour ouvrir la boîte de dialogue « Copier la liste de contrôle ». Ajustez le titre et sélectionnez [Dupliquer]. La nouvelle liste de contrôle est créée comme une copie de la liste sélectionnée et affichée dans l'aperçu.

Points de contrôle/Questions: Dans une carte de checklist, appuyez sur l'icône de la question (💬), l'écran « Points de contrôle/Questions » s'ouvre. Ici, vous gérez les points de contrôle et Questions pour la liste de contrôle sélectionnée. Vous pouvez découvrir comment faire cela un peu plus bas dans le chapitre [Points de contrôle / Questions].

Liste de contrôle Supprimer: Dans une carte de liste, appuyez sur l'icône supprimer (🗑️), Une fenêtre s'ouvre dans laquelle vous devez confirmer la suppression. Suppression d'un La liste de contrôle supprime automatiquement les questions associées. Veuillez noter : Listes de contrôle, à qui ont déjà eu un journal enregistré, ne peuvent pas être supprimés.

Afficher le graphique: Si au moins 3 protocoles ont été enregistrés pour une liste de contrôle, le symbole du graphique (📋) est affiché. Avec cette icône, vous ouvrez l'écran du graphique. Cela montre dans un premier graphique combien de rapports de tests ont été enregistrés par jour. Si la liste contient une question sur le nombre, un second graphique montre la courbe pour la première valeur du nombre. Si la liste contient deux questions de nombres, un troisième graphique montre les courbes des deux premières valeurs de nombres.

Consultez et ajoutez les journaux d'examen: dans une carte de checklist, appuyez sur le Icône de journal (📋), l'écran « Mes journaux » s'ouvre. Celle-ci liste les protocoles enregistrés pour la liste de contrôle sélectionnée. Vous pouvez aussi ajouter des journaux ici.

Points de contrôle / Questions

Sur cet écran, vous gérez les points de contrôle/questions d'une liste de contrôle. Pour cela, Prend en charge les types de réponses suivants : texte, numéro, case à cocher, liste de choix simple, Liste de sélection multiple, NFC et code QR.

- Texte : Entrée de texte flexible

- Numéro : Entrée de valeurs numériques. Vous pouvez définir un minimum et un Valeur maximale. Celles-ci ne doivent donc pas être sous-estimées ou dépassées lors de l'entrée.

- Case à cocher : Bascule Oui/Non

- Liste de sélection : Les options possibles doivent être saisies séparées par des virgules. Une option est ensuite sélectionné lors du remplissage de la liste de contrôle. Vous pouvez également choisir les couleurs d'arrière-plan (vert, jaune ou rouge) en insérant des balises de couleur entre parenthèses, comme sans Défauts reconnaissables [vert], réparation requise [rouge] ou défauts éliminés [jaune]. Dans le L'export PDF affichera l'option sélectionnée avec une case d'arrière-plan surlignée imprimé.

- Sélection multiple : Les options possibles doivent être saisies séparées par des virgules. Une ou plusieurs Plusieurs options sont ensuite sélectionnées lors de la compilation de la liste de contrôle. Vous pouvez aussi Spécifiez les couleurs d'arrière-plan (vert, jaune ou rouge) en ajoutant des balises de couleur entre parenthèses, telles que par exemple, options 1 [vert], option 2 [rouge] ou option 3 [jaune]. Dans l'export PDF, le Option sélectionnée avec une case d'arrière-plan surlignée.

- NFC : Lire les étiquettes NFC physiques et transférer les données

- Code QR : Scanner les codes QR avec la caméra et ajouter la valeur contenue à la Accepter le champ de réponse.

Ajouter un point de contrôle/question : Il suffit de cliquer sur le bouton **'+'** dans le Coin inférieur right . La boîte de dialogue « Ajouter un point de contrôle/question » s'ouvre. Dans le champ Titre, saisissez un nom pour votre nouveau point de contrôle/question et organisez votre organisation un type de réponse. Selon le type de réponse, des informations supplémentaires sont nécessaires ou possibles. Si vous voulez, entrez une courte description. Vous pouvez aussi entrer le numéro de tri, mais l'application le fera automatiquement pour vous. Les nouveaux points de contrôle/questions sont automatiquement marqués comme requis. Changez-les L'attitude si la question n'a pas nécessairement besoin d'une réponse. Avec le bouton « Enregistrer », vos entrées seront sauvegardées et stockées dans l'aperçu affiché.

Ajuster l'ordre : Le numéro de tri est affiché pour chaque entrée (par exemple, #1, #2). Cela contrôle la position dans la liste. Utilisez le Flèches haut (↑)/bas (↓) pour ajuster l'ordre des questions. Un changement cela fait que les numéros de tri des autres entrées sont automatiquement ajustés.

Modification du point de contrôle/question : Appuyez sur l'icône Modifier (✏️), la boîte « Modifier le point de contrôle/Question » s'ouvre. Ici, vous pouvez sélectionner le titre, le description, numéro de tri, type de réponse. Bien sûr, vous pouvez aussi que l'inscription soit obligatoire ou optionnelle.

Supprimer le point de contrôle/question : Appuyez sur l'icône supprimer (🗑️), Une fenêtre s'ouvre dans laquelle vous devez confirmer la suppression.

Mes Journaux

Cliquez sur la carte « Mes journaux » dans le tableau de bord et ouvrez la écran correspondant. Voir les journaux enregistrés, filtrer la liste, Corrigez vos réponses et créez immédiatement votre rapport PDF A4.

Paramètres: Si vous cliquez sur l'icône d'engrenage (⚙), la boîte de dialogue « PDF Report Designer » s'ouvre. Personnalisez la mise en page des rapports PDF (en-tête, pied de page, les saut de page, l'affichage de la date et du statut). Pour les images, vous pouvez ajuster vos valeurs pour S, M, L selon vos préférences. Par défaut, 100px est utilisé pour S, 200px pour M, et 300px pour L.

Ajouter des minutes: Il suffit de cliquer sur le bouton **'+'** en bas à droite. Pour plus d'informations, voir le chapitre [Effectuer des Inspections].

Recherche de journaux: Appuyez sur l'icône de recherche (🔍) dans la barre supérieure pour Trouvez les procès-verbaux par date, titre ou notes.

Filtrez les listes de contrôle par statut: Filtrez la liste en tapotant un statut (Terminé, en cours). Cliquer sur Tout enlève le filtre.

Journal d'édition: Dans une carte, appuyez sur l'icône Modifier (✏️), s'ouvre la fenêtre « Modifier le protocole » et vous pouvez ajuster vos entrées.

Delete log: Appuyez sur l'icône supprimer (🗑️) dans une carte, ouvre Une fenêtre dans laquelle vous devez confirmer la suppression.

Suppression d'un journal: Supprime toutes les réponses associées.

Voir PDF: Appuyez sur l'icône PDF sur une carte, ouvre une Visualiseur PDF et affiche le PDF généré. Vous pouvez ensuite l'imprimer ou le partager. Si vous avez besoin d'une nouvelle version du PDF, appuyez sur l'icône Modifier (✏️) dans une carte. Dans la fenêtre du journal d'édition, sauvegardez à nouveau le journal. Une fois toutes les questions nécessaires répondues, un nouveau fichier PDF sera créé. Attendez que le message de l'application ne soit plus visible avant de cliquer sur l'icône PDF.

Effectuer des Inspections

Cliquez sur la carte « Mes listes de contrôle » dans le tableau de bord et ouvrez le écran correspondant. Cliquez sur une carte de liste de contrôle pour commencer le Enregistrement d'un examen. Le formulaire « Remplir la liste de contrôle » s'ouvre.

- Évaluateur: Le nom du critique a été automatiquement rempli depuis les paramètres. Vous peut changer ça.

- Date d'inspection: La date a été prédéfinie avec la date actuelle (actuellement fixée dd.MM.yyy). Tu peux changer ça.

- Statut: Le statut a été prédéfini sur « en cours ». Pour l'instant, vous pouvez définir le Statut. Mais cela sera désactivé.

- Notes: Si vous le souhaitez, vous pouvez ajouter des informations supplémentaires sur l'examen dans les notes. Utilisez cette option, car les notes sont affichées dans l'aperçu du journal. Cela facilite la recherche d'un examen.

- Points de contrôle/Questions: Répondez maintenant à toutes les questions obligatoires de la liste de contrôle. Vous Peut sauvegarder la modification à tout moment et continuer plus tard. Utilisez le Bouton d'enregistrement dans la zone en-tête du formulaire. De plus, vous trouverez un bouton d'enregistrement également à la fin de la liste. Si toutes les questions nécessaires n'ont pas été répondues, Le statut est prédéfini avec « en cours ». Si tous les points de contrôle/questions requis ont été définis ont été répondues, le statut est automatiquement changé en « Terminé » lors de la sauvegarde.

- Tags NFC: Pour les questions NFC, appuyez sur le bouton NFC et maintenez une Étiquette NFC à l'arrière de votre appareil pour qu'il puisse être scanné. Quand tout a fonctionné, les données ont été transférées dans le champ de réponse. Veuillez noter que ceci Sur votre appareil.

- Codes QR: Pour les questions sur les codes QR, appuyez sur le bouton « Scanner le code QR ». Donc Le scanner de caméra s'ouvre et tu peux enregistrer le code. Si tout s'est bien passé, Les données ont été transférées dans le champ de réponse. Veuillez noter que l'application Autorisations de caméra requises.

- Ajouter une image: Appuyez sur l'icône « Prendre une image » ou « Télécharger l'image » pour ajouter une photo à une réponse. Les images sont stockées dans le dossier sécurisé de l'application (/data/data/com.pobvol.mychecks). Utilisez les icônes « S », « M », « L » pour spécifier la taille dans laquelle une image doit être produite dans le document PDF. S représente une largeur de 100px, M une largeur de 200px et L une largeur de 300px. Vous pouvez définir cela individuellement pour chaque image / réponse.

- Fichiers PDF et SQL: Les fichiers PDF et SQL sont automatiquement créés pour les listes de contrôle entièrement complétées dès que tous des données ont été collectées. Le statut est automatiquement réglé sur « Terminé ». Un fichier PDF sera enregistré dans le dossier Download/pobvolMyChecks/pdf. Un fichier SQL est stocké dans le dossier Download/pobvolMyChecks/sql. Pour chaque fichier SQL, un fichier supplémentaire avec la somme de contrôle correspondante est stocké dans le dossier sql. Si des images ont été ajoutées, elles sont également copiées dans le dossier sql.

Sécurité des données & Export

Toutes les données sont stockées sur votre appareil. Vos paramètres personnels sont stockés dans une zone sécurisée de l'application (/data/data/com.pobvol.mychecks/shared_prefs). Les catégories, modules de texte, listes de contrôle, points de contrôle/questions, données d'inspection et réponses sont stockés dans une base de données locale Android SQLite. Celle-ci se trouve également dans la zone sécurisée de l'application (/data/data/com.pobvol.mychecks/databases).

Sauvegarde et export des données : Vous pouvez créer une copie de sauvegarde de la base de données à tout moment via l'écran d'accueil (élément de menu "Créer une copie de la base de données"). L'application crée automatiquement des fichiers PDF et SQL dès qu'un contrôle est terminé. Les copies de la base de données, les fichiers PDF et SQL se trouvent dans le dossier de téléchargement, sous-dossier pobvolMyChecks. Dans ce dossier, vous trouverez un sous-dossier portant l'ID de l'appareil de l'application. Dans ce sous-dossier, les données exportées sont ensuite enregistrées dans les dossiers dbbackup, pdf et sql. Vous pouvez copier ces données sur un PC ou un autre appareil pour les sauvegarder.

L'application ne transfère aucune donnée vers le cloud ou vers des serveurs tiers.

🛠️ Technologie / Architecture

- Langage de développement: Kotlin
- Framework UI: Jetpack Compose & Material 3 (avec support Edge-to-Edge)
- Base de données: Room Persistence Library (SQLite avec migrations automatiques de schéma & Suppression en cascade)
- Création de documents: API 'PdfDocument' Android (rendu vectoriel A4)
- Traitement d'image: Composition en bobine
- Autorisations & Matériel: Contrats caméra, dispatch NFC au premier plan, et Scope API Storage MediaStore
- Appareils pris en charge: smartphones et tablettes Android
- Langues prises en charge: allemand, anglais, espagnol et français
