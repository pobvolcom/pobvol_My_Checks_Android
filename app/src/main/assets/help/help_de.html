My Checks - Benutzerhilfe

Mit der Android-App pobvol My Checks können Sie ganz einfach und schnell eigene Checklisten mit Kontrollpunkten und Fragen erstellen und anschließend die Ergebnisse von Prüfungen und anderen Aktivitäten festhalten, analysieren und in PDF-Protokollen ausgeben. Alle erfassten Daten werden automatisch in SQL-Dateien gesichert. Datenstrukturen müssen nicht mit großem Aufwand in Datenbanken programmiert werden. Deutsch, Englisch, Spanisch und Französisch werden unterstützt.

Dashboard & Navigation

Das Dashboard ist Ihr Startpunkt. Navigieren Sie mit den Karten zu Ihren Checklisten und Protokollen und greifen Sie über die obere Leiste auf Einstellungen und Hilfe zu. Über das Menü-Icon in der linken oberen Ecke können Sie die Lizenzvereinbarung einsehen, eigene Textblöcke verwalten, die Datenbank sichern, Sicherungen der Datenbank wieder importieren und die App beenden.

Einstellungen

Klicken Sie im Dashboard auf das Zahnrad-Symbol (⚙). Es öffnet sich der Dialog "Allgemeine Einstellungen". Passen Sie das Erscheinungsbild, die bevorzugte Sprache und die Kategorien an Ihre Bedürfnisse an. Tragen Sie Ihren Namen in das Feld Prüfer ein. Ihr Name wird damit in die Protokolle übernommen und im PDF ausgegeben.

Meine Checklisten

Klicken Sie im Dashboard auf die Karte "Meine Checklisten" und öffnen Sie damit den entsprechenden Bildschirm.

Checkliste hinzufügen: Neue Checklisten erstellen Sie recht schnell. Klicken Sie einfach auf den **`+`** Button in der unteren rechten Ecke. Es öffnet sich der Dialog "Checkliste hinzufügen". Tragen Sie im Feld Titel einen Namen für Ihre neue Checkliste ein, ordnen Sie eine Kategorie zu und wenn Sie mögen, geben Sie eine kurze Beschreibung ein. Mit dem Button "Hinzufügen" werden Ihre Eingaben gespeichert, Ihre neue Checkliste wird erstellt und in der Übersicht angezeigt.

Checklisten suchen: Tippen Sie auf das Suchsymbol (🔍) in der oberen Leiste, um Checklisten nach Titel, Beschreibung oder Kategorie zu finden.

Checklisten nach Kategorie filtern: Filtern Sie die Liste, indem Sie auf eine Kategorie tippen (Health, UVV, usw.). Ein Klick auf All hebt den Filter wieder auf.

Checkliste bearbeiten: Tippen Sie in einer Checklistenkarte auf das Ändern-Symbol (✏️), öffnet sich das Fenster "Checkliste bearbeiten". Hier können Sie den Titel, die Kategorie und die Beschreibung anpassen.

Checkliste kopieren: Tippen Sie in einer Checklistenkarte auf das Kopieren-Symbol (📄), öffnet sich das Fenster "Checkliste kopieren". Passen Sie den Titel an und wählen Sie [Kopieren]. Die neue Checkliste wird als Kopie der gewählten Checkliste erstellt und in der Übersicht angezeigt.

Checkpunkte/Fragen: Tippen Sie in einer Checklistenkarte auf das Frage-Symbol (💬), öffnet sich der Bildschirm "Checkpunkte/Fragen". Hier verwalten Sie die Checkpunkte und Fragen für die gewählte Checkliste. Wie das geht, finden Sie etwas weiter unten im Kapitel [Checkpunkte/Fragen].

Checkliste löschen: Tippen Sie in einer Checklistenkarte auf das Lösch-Symbol (🗑️), öffnet sich ein Fenster, in welchem Sie die Löschung bestätigen müssen. Das Löschen einer Checkliste löscht automatisch die zugehörigen Fragen. Bitte beachten Sie: Checklisten, zu denen bereits ein Protokoll erfasst wurde, können nicht gelöscht werden.

Prüfung hinzufügen: Mit einem Klick auf eine Checklistenkarte starten Sie die Erfassung einer Prüfung. Es öffnet sich das Formular "Checkliste ausfüllen".

Chart anzeigen: Tippen Sie in einer Checklistenkarte auf das Chart-Symbol (📋), öffnet sich der Chart-Bildschirm. Dieser zeigt in einem ersten Chart, wieviele Prüfberichte pro Tag erfasst wurden. Enthält die Checkliste eine Nummernfrage, zeigt ein zweites Chart die Kurve für den ersten Nummernwert. Enthält die Checkliste zwei Nummernfragen, zeigt ein drittes Chart die Kurve für die ersten beiden Nummernwerte.

Prüfungsprotokolle anzeigen: Tippen Sie in einer Checklistenkarte auf das Protokoll-Symbol (📋), öffnet sich der Bildschirm "Meine Protokolle". Dieser listet die Protokolle für die gewählte Checkliste.

Checkpunkte/Fragen

Auf diesem Bildschirm verwalten Sie die Checkpunkte/Fragen einer Checkliste. Dazu werden folgende Antworttypen unterstützt: Text, Zahl, Kontrollkästchen, einfache Auswahlliste, Mehrfachauswahlliste, NFC und QR-Code.

- Text: Flexible Texteingaben

- Zahl: Eingabe von numerischen Werten. Sie können einen Minimum- und einen Maximumwert zuordnen. Diese dürfen dann bei der Eingabe nicht unter- bzw. überschritten werden.

- Kontrollkästchen: Ja/Nein-Umschalter

- Auswahlliste: Mögliche Optionen müssen kommagetrennt erfasst werden. Eine Option wird dann beim Ausfüllen der Checkliste ausgewählt. Man kann auch Hintergrundfarben (grün, gelb oder rot) angeben, indem man Farbtags in Klammern einfügt, wie zum Beispiel ohne erkennbare Mängel [grün], Reparatur erforderlich [rot] oder Mängel beseitigt [gelb]. Im PDF-Export wird die ausgewählte Option mit einem farblich hervorgehobenen Hintergrundfeld gedruckt.

- Mehrfachauswahl: Mögliche Optionen müssen kommagetrennt erfasst werden. Eine oder mehrere Optionen werden dann beim Ausfüllen der Checkliste ausgewählt. Man kann auch Hintergrundfarben (grün, gelb oder rot) angeben, indem man Farbtags in Klammern einfügt, wie zum Beispiel Optionn 1 [grün], Option 2 [rot] oder Option 3 [gelb]. Im PDF-Export wird die ausgewählte Option mit einem farblich hervorgehobenen Hintergrundfeld gedruckt.

- NFC: Physische NFC-Tags auslesen und die Daten übernehmen

- QR-Code: QR-Codes mit der Kamera scannen und den enthaltenen Wert in das Antwortfeld übernehmen.


Checkpunkt/Frage hinzufügen: Klicken Sie einfach auf den **`+`** Button in der unteren rechten Ecke. Es öffnet sich der Dialog "Checkpunkt/Frage hinzufügen". Tragen Sie im Feld Titel einen Namen für Ihren neuen Checkpunkt/Frage ein und ordnen Sie einen Antworttyp zu. Abhängig vom Antworttyp sind weitere Angaben erforderlich oder möglich. Wenn Sie mögen, geben Sie eine kurze Beschreibung ein. Sie können auch die Sortiernummer eintragen, das macht die App aber für Sie automatisch. Neue Checkpunkte/Fragen werden automatisch als erforderlich markiert. Ändern Sie diese Einstellung, wenn die Frage nicht unbedingt beantwortet werden muss. Mit dem Button "Speichern" werden Ihre Eingaben gespeichert und in der Übersicht angezeigt.

Reihenfolge anpassen: Zu jedem Eintrag wird die Sortiernummer angezeigt (e.g., #1, #2). Damit wird die Position in der Liste gesteuert. Verwenden Sie die Aufwärts-(↑)/Abwärts-Pfeile(↓), um die Reihenfolge der Fragen anzupassen. Eine Änderung bewirkt, dass die Sortiernummern anderer Einträge automatisch angepasst werden.

Checkpunkt/Frage bearbeiten: Tippen Sie bei einem Eintrag auf das Ändern-Symbol (✏️), öffnet sich der Dialog "Checkpunkt/Frage bearbeiten". Hier können Sie den Titel, die Beschreibung, die Sortiernummer, den Antworttyp anpassen. Natürlich können Sie auch anpassen, ob der Eintrag erforderlich oder optional ist.

Checkpunkt/Frage löschen: Tippen Sie bei einem Eintrag auf das Lösch-Symbol (🗑️), öffnet sich ein Fenster, in welchem Sie die Löschung bestätigen müssen.

Prüfungen durchführen und Ergebnisse erfassen

Klicken Sie im Dashboard auf die Karte "Meine Checklisten" und öffnen Sie damit den entsprechenden Bildschirm. Mit einem Klick auf eine Checklistenkarte starten Sie die Erfassung einer Prüfung. Es öffnet sich das Formular "Checkliste ausfüllen".

- Prüfer: Der Prüfername wurde automatisch aus den Einstellungen ausgefüllt. Sie können diesen ändern.

- Prüfdatum: Das Datum wurde mit dem aktuellen Datum vorbelegt (zur Zeit fest dd.MM.yyyyy). Sie können dieses ändern.

- Notizen: Wenn Sie mögen, können Sie zusätzliche Angaben zur Prüfung in den Notizen eintragen. Nutzen Sie diese Möglichkeit, da die Notizen in der Protokollübersicht angezeigt werden. Das erleichtert Ihnen das Auffinden einer Prüfung.

- Checkpunkte/Fragen: Beantworten Sie nun alle erforderlichen Checklistenfragen. Sie können die Bearbeitung jederzeit speichern und später weitermachen. Nutzen Sie dazu den Speichern-Button im Kopfbereich des Formulars. Zusätzlich finden Sie einen Speicherbutton auch am Ende der Liste. Sollten noch nicht alle erforderlichen Fragen beantwortet sein, wird der Status mit "in Bearbeitung" vorbelegt. Wenn alle erfordferlichen Checkpunkte/Fragen beantwortet wurden, wird der Status beim Speichern automatisch auf "Abgeschlossen" geändert.

- NFC Tags: Für NFC-Fragen tippen Sie auf den NFC-Button und halten Sie einen NFC-Tag an die Rückseite Ihres Geräts, damit dieser gescannt werden kann. Wenn alles geklappt hat, wurden die Daten in das Antwortfeld übernommen. Bitte beachten Sie, dass dazu auf Ihrem Gerät NFC eingeschaltet sein muss.

- QR-Codes: Für QR-Code-Fragen tippen Sie auf den Button "QR-Code scannen". Damit öffnet sich der Kamerascanner und Sie können den Code aufnehmen. Wenn alles geklappt hat, wurden die Daten in das Antwortfeld übernommen. Bitte beachten Sie, dass die App dazu Kamera-Berechtigungen benötigt.

- Bild hinzufügen: Tippen Sie auf das Icon "Bild aufnehmen" oder das Icon "Bild hochladen", um ein Foto zu einer Antwort hinzuzufügen. Bilder werden in dem abgesicherten App-Ordner (/data/data/com.pobvol.mychecks) gespeichert. Legen Sie über die Icons "S", "M", "L" fest, in welcher Größe ein Bild im PDF-Dokument ausgegeben werden soll. S steht für eine Breite von 100px, M für eine Breite von 200px und L für eine Breite von 300px. Das können Sie pro Bild / Antwort individuell festlegen.

- PDF- und SQL-Dateien: PDF- und SQL-Dateien werden für vollständig ausgefüllte Checklisten automatisch erstellt, sobald alle erforderlichen Daten erfasst wurden. Der Status wird automatisch auf "Abgeschlossen" gesetzt. Eine PDF-Datei wird in dem Ordner Download/pobvolMyChecks/pdf gespeichert. Eine SQL-Datei wird in dem Ordner Download/pobvolMyChecks/sql gespeichert. Für jede SQL-Datei wird zusätzlich eine Datei mit der entsprechenden Checksumme in dem sql-Ordner gespeichert. Wurden Bilder hinzugefügt, werden diese ebenfalls in den sql-Ordner kopiert.

Meine Protokolle

Klicken Sie im Dashboard auf die Karte "Meine Protokolle" und öffnen Sie damit den entsprechenden Bildschirm. Sehen Sie aufgezeichnete Protokolle an, filtern Sie die Liste, bearbeiten Sie Ihre Antworten und erstellen Sie sofort Ihren DIN A4 PDF-Bericht.

Einstellungen: Klicken Sie auf das Zahnrad-Symbol (⚙), öffnet sich der Dialog "PDF-Berichts-Designer". Passen Sie das Layout der PDF-Berichte (Kopfzeile, Fußzeile, Seitenumbrüche, Datums- und Statusanzeige) an. Für Bilder können Sie Ihre Werte für S, M, L an Ihre Wünsche anpassen. Standardmäßig wird 100px für S, 200px für M und 300px für L verwendet.

Protokolle suchen: Tippen Sie auf das Suchsymbol (🔍) in der oberen Leiste, um Protokolle nach Datum, Titel oder Notizen zu finden.

Checklisten nach Status filtern: Filtern Sie die Liste, indem Sie auf einen Status tippen (Abgeschlossen, In Bearbeitung). Ein Klick auf Alle hebt den Filter wieder auf.

Protokoll bearbeiten: Tippen Sie in einer Karte auf das Ändern-Symbol (✏️), öffnet sich das Fenster "Protokoll bearbeiten" und Sie können Ihre Eingaben anpassen.

Protokoll löschen: Tippen Sie in einer Karte auf das Lösch-Symbol (🗑️), öffnet sich ein Fenster, in welchem Sie die Löschung bestätigen müssen. Das Löschen eines Protokolls löscht alle zugehörigen Antworten.

PDF anzeigen: Tippen Sie in einer Karte auf das PDF-Symbol, öffnet sich ein PDF-Viewer und zeigt das erzeugte PDF an. Dieses können Sie dann drucken oder teilen.

Datensicherheit

Daten werden nur auf Ihrem Gerät gespeichert. Ihre persönlichen Einstellungen liegen in einem abgesicherten Bereich der App (/data/data/com.pobvol.mychecks/shared_prefs). Kategorien, Textbausteine, Checklisten, Checkpunkte/Fragen, Prüfungsdaten und Antworten werden in einer lokalen Android SQLite-Datenbank gespeichert. Auch diese liegt in dem abgesicherten Bereich der App (/data/data/com.pobvol.mychecks/databases).

Datensicherung und Datenexport: Sie können jederzeit über den Startbildschirm (Menüpunkt "Datenbank sichern)" eine Sicherungskopie der Datenbank erstellen. PDF- und SQL-Dateien erstellt die App automatisch, sobald eine Prüfung abgeschlossen ist. Datenbankkopien, PDF- und SQL-Dateien finden Sie in ihrem Download-Folder, Unterordner pobvolMyChecks. In diesem Unterordner liegen die exportierten Daten dann in den Ordnern dbbackup, pdf und sql. Sie können diese Daten auf einen PC oder ein anderes Gerät kopieren und sichern.

Die App selbst überträgt keine Daten in die Cloud oder auf fremde Server.

🛠️ Technik / Architektur

- Entwicklungssprache: Kotlin
- UI Framework: Jetpack Compose & Material 3 (with Edge-to-Edge support)
- Datenbank: Room Persistence Library (SQLite with automatic schema migrations & cascade deletes)
- Dokumentenerstellung: Android `PdfDocument` API (A4 vector rendering)
- Bildverarbeitung: Coil Compose
- **Permissions & Hardware: Camera contracts, NFC foreground dispatch, and Scoped Storage MediaStore APIs - Unterstützte Geräte: Android Smartphones und Tablets
- Unterstützte Sprachen: Deutsch, Englisch, Spanisch und Französisch
